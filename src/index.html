사용 안내

  • 지도를 더블클릭하면 마커가 생성됩니다. 각 마커의 X 버튼으로 삭제할 수 있습니다. 클릭 드래그로 이동 마우스 휠로 확대 축소 가능합니다.
  • 기본적으로 자동저장입니다 캐시초기화 다른 브라우저 이용 같은게 아니면 다시 접속했을때 자동으로 마커를 불러옵니다.
  • 자동 저장이 안됐을 경우를 대비한 백업 대책이 있습니다 우측 상단 버튼으로 링크/백업 파일로 저장·복원할 수 있습니다.
  • 링크 저장은 현재 마커를 URL에 인코딩해 복사합니다 링크를 다른곳에 저장 후 나중에 붙여넣으면 마커를 불러올 수 있습니다.
  • 버그 제보는 안받습니다. 이용하는데 심각한 오류가 있는게 아니라면 그냥 무시해주세요.
